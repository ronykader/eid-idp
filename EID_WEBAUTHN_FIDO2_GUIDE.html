FIDO2 & WebAuthn Guide

Understanding WebAuthn & FIDO2

Technical briefing on passwordless public-key cryptography

🛡️ Why is WebAuthn Important?

WebAuthn (Web Authentication API) is a global W3C standard developed to completely eliminate traditional passwords and replace them with secure, un-phishable cryptographic credentials.

Traditional Passwords

  • Vulnerable to phishing sites masquerading as the official eID portal.
  • Users reuse credentials, causing leaks on unrelated sites to compromise government accounts.
  • Stored on backend servers as hashes; if a database is breached, passwords are targeted for offline brute-forcing.

FIDO2 & WebAuthn

  • Phishing Resistant: Credentials are cryptographically bound to the specific domain name (domain-bound). Browser blocks handshake if spoofed.
  • Zero Shared Secrets: The server never receives or stores your password or biometric template. Touch ID/YubiKey remains local.
  • Asymmetric Cryptography: The private key remains locked inside the device's hardware enclave; the server only retains the public key.

🔄 The Cryptographic Registration Flow (Binding)

When a citizen clicks "Bind New Biometric / Hardware Key" on their dashboard, the system initiates a handshake to generate a new key pair:

Step 1

Get Challenge from Backend

The Next.js client requests a cryptographically random challenge from the C# WebAuthn endpoint. This challenge prevents replay attacks.

Step 2

Prompt Browser Navigator

The browser invokes navigator.credentials.create(). The operating system prompts the user for Touch ID, Face ID, or YubiKey pin.

Step 3

Generate Cryptographic Key Pair

The device's secure hardware enclave generates a brand new, unique key pair. The private key remains inside the enclave. The public key is sent back to the browser.

Step 4

Register Public Key in Database

The client sends the public key and credential ID to the C# backend, which saves it in the credentials table for future login validations.

javascript_api_call.js (Registration)
// 1. Prompt the browser to generate new asymmetric credentials
const credential = await navigator.credentials.create({
  publicKey: {
    challenge: Uint8Array.from(challengeBuffer),
    rp: { name: "Sint Maarten eID", id: "localhost" },
    user: {
      id: Uint8Array.from(userBuffer),
      name: "citizen@eid.sm",
      displayName: "John Connor"
    },
    pubKeyCredParams: [{ type: "public-key", alg: -7 }], // ES256 algorithm
    authenticatorSelection: { authenticatorAttachment: "platform" }, // Touch ID / Face ID
    timeout: 60000
  }
});

🔑 The Authentication Flow (Login)

When the citizen logs in later using their passkey, they bypass password and MFA screens completely via a cryptographic signature challenge:

Step 1

Send Auth Challenge

The server sends an authentication challenge to the client along with the citizen's registered Credential ID.

Step 2

Prompt Cryptographic Signature

The browser invokes navigator.credentials.get(). The user unlocks their biometric sensor (Touch ID). The device signs the challenge using the stored private key.

Step 3

Validate Signature on Server

The signed assertion is sent back to the C# backend. The backend retrieves the corresponding public key and verifies that the signature matches the challenge. If verified, access is granted.

javascript_api_call.js (Authentication)
// 2. Prompt browser to sign authentication challenge
const assertion = await navigator.credentials.get({
  publicKey: {
    challenge: Uint8Array.from(challengeBuffer),
    allowCredentials: [{
      id: Uint8Array.from(credentialIdBuffer),
      type: "public-key"
    }],
    timeout: 60000
  }
});
WebAuthnController.cs (C# Backend Validation)
// C# Backend verification checks
[HttpPost("login/verify")]
public IActionResult VerifyAssertion([FromBody] AssertionVerifyRequest req)
{
    var credential = _dbContext.Credentials.FirstOrDefault(c => c.Uin == req.Uin);
    if (credential == null) return NotFound();

    // Cryptographic verification of client signature using stored public key
    bool isValid = Cryptography.VerifySignature(
        publicKey: credential.PublicKey,
        data: req.ClientDataJSON + req.AuthenticatorData,
        signature: req.Signature
    );

    if (!isValid) return Unauthorized("Invalid passkey signature");
    
    return Ok(new { token = GenerateToken(credential.Citizen) });
}
