📚 OpenID Connect & WSO2 Integration Playbook

Follow this implementation loop to integrate your Relying Party application with the WSO2 Identity Server broker utilizing standard OID/PKCE authorization protocols.

1. Generate PKCE & Redirect to Authorize
Generate a cryptographically secure code_verifier and compute its SHA-256 hash to create the code_challenge. Redirect the citizen's browser to the authorize endpoint: 
https://identity.sintmaarten.gov/oauth2/authorize?
  response_type=code
  &client_id=mygov-client-id-2026
  &redirect_uri=https://mygov.sintmaarten.gov/auth/wso2/callback
  &scope=openid+profile+uin+bsn_number
  &code_challenge=E9Melhoa2OwvFrGMTJguCH5yOFzDHYU913Vfzzc
  &code_challenge_method=S256
  &state=xyzSecretState
  &nonce=randomSessionNonce
2. Backchannel Code Exchange
Upon callback validation, make a secure server-to-server POST request to WSO2's token endpoint, authenticating with your rotated Client Secret: 
POST https://identity.sintmaarten.gov/oauth2/token
Headers:
  Content-Type: application/x-www-form-urlencoded
  Authorization: Basic <Base64(ClientID:RotatedSecret)>

Payload:
  grant_type=authorization_code
  &code=auth_code_from_callback
  &redirect_uri=https://mygov.sintmaarten.gov/auth/wso2/callback
  &code_verifier=myOriginalCodeVerifierString
3. Validate RS256 Assertion Signature
Retrieve the ID token from WSO2's response, query eID's JSON Web Key Set (JWKS) to fetch public parameters, and verify the token signature using RS256 algorithm: 
// Sample Node.js JWT verify validation loop
const jwt = require('jsonwebtoken');
const jwksClient = require('jwks-rsa');

const client = jwksClient({
  jwksUri: 'https://eid.sintmaarten.gov/.well-known/jwks.json'
});

function getKey(header, callback){
  client.getSigningKey(header.kid, function(err, key) {
    callback(null, key.getPublicKey());
  });
}

jwt.verify(idToken, getKey, { 
  audience: 'mygov-client-id-2026',
  issuer: 'https://identity.sintmaarten.gov'
}, function(err, decoded) {
  // Access validated claims securely
});
