🔒 Configuring MFA in WSO2 IS Console

If you need to enforce WSO2 IS native MFA policies (Google Authenticator / SMS) for additional Service Providers:

  • Login to Admin Portal
    Go to WSO2 Console and log in as admin / admin.
  • Manage Applications
    Navigate to Applications ➔ Select "MyGov Portal".
  • Configure Authentication Steps
    Go to the "Sign-in Method" tab ➔ Add step 1 (Federated IDP - eID) ➔ Add step 2 (TOTP / Email OTP).
  • Save & Enforce
    Click update. WSO2 IS will now natively double-verify the citizen's authentication after receiving the token from our eID platform.
