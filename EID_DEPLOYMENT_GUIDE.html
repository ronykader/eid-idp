1. Security Architecture & UFW Firewall

To prevent brute force credentials mining, only ports 80, 443, and a custom SSH port are exposed to the public. Internal app ports like 8082 (.NET backend), 9443 (WSO2), and 3306 (MySQL) are bound exclusively to 127.0.0.1 and proxies via Nginx. 

# Install UFW Firewall on Ubuntu Server
sudo apt update && sudo apt install ufw -y

# Configure default deny rules
sudo ufw default deny incoming
sudo ufw default allow outgoing

# Allow standard web entry ports
sudo ufw allow 80/tcp
sudo ufw allow 443/tcp

# Allow SSH (replace 22 with your hardened SSH port if modified)
sudo ufw allow 22/tcp

# Enable firewall daemon
sudo ufw enable

# Check active rules
sudo ufw status verbose

2. Database Installation & Hardening

Install MySQL Server and enforce access limits. Do not allow root connection logins from external IP addresses. 

# Install MySQL Server
sudo apt install mysql-server -y

# Start and enable daemon
sudo systemctl start mysql
sudo systemctl enable mysql

# Execute automated security script
sudo mysql_secure_installation
# -> Enforce validation password policy
# -> Remove anonymous users
# -> Disallow root login remotely
# -> Remove test database

# Create eID project user and database schema
sudo mysql -u root -p -e "
CREATE DATABASE IF NOT EXISTS eid_mvp_db CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER 'eid_mvp_user'@'localhost' IDENTIFIED WITH mysql_native_password BY 'ProdSecurePassWord2026!';
GRANT ALL PRIVILEGES ON eid_mvp_db.* TO 'eid_mvp_user'@'localhost';
FLUSH PRIVILEGES;
"

3. WSO2 Identity Server Installation

WSO2 requires Java JRE 17 runtime baseline. Install JDK, pull WSO2 source archives, and set up a systemd background service. 

# Install JRE JDK 17
sudo apt install openjdk-17-jdk -y

# Create system user for WSO2 execution (no shell log-in)
sudo useradd -r -m -U -d /opt/wso2 -s /bin/false wso2

# Download and unzip WSO2 Identity Server into /opt/
cd /tmp
wget https://github.com/wso2/product-is/releases/download/v6.1.0/wso2is-6.1.0.zip
sudo apt install unzip -y
sudo unzip wso2is-6.1.0.zip -d /opt/
sudo mv /opt/wso2is-6.1.0 /opt/wso2/server
sudo chown -R wso2:wso2 /opt/wso2

5. Next.js Frontend PM2 Deployment

Deploy Node environment. Configure PM2 process manager for automated load balancing and zero-downtime crashes restarts. 

# Install Node.js v20 LTS
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt-get install -y nodejs

# Install PM2 Process Manager globally
sudo npm install pm2 -g

# Install dependencies and build Next.js source codes
cd /opt
sudo git clone https://github.com/yourorg/eid-frontend.git /opt/eid-frontend
cd /opt/eid-frontend
sudo npm install
sudo npm run build

# Start Next.js server cluster under PM2
pm2 start npm --name "eid-frontend" -- run start -- -p 3000

# Save process list and register startup scripts
pm2 save
pm2 startup
# -> Copy and paste the resulting script command printed on your console screen to persist reboot configurations
