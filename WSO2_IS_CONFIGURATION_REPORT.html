🔍 3. Programmatic Configuration Verification

Run these terminal curl commands from the command line to verify WSO2 config states directly:

# 1. Fetch Registered Claims Dialects curl -k -s -u admin:admin https://localhost:9443/api/server/v1/claim-dialects # 2. Check Custom Claims in Local Dialect curl -k -s -u admin:admin https://localhost:9443/api/server/v1/claim-dialects/local/claims | grep -o -E '"claimURI":"[^"]+"' # 3. Retrieve Registered Service Providers curl -k -s -u admin:admin https://localhost:9443/api/server/v1/applications
