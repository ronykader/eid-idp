WSO2 Identity Server vs. Sint Maarten eID Platform

A comprehensive breakdown of duties between the WSO2 Enterprise SSO Gateway and the Sint Maarten National eID Verification Vault.

🌐

WSO2 Identity Server

Enterprise Access & Gateway Layer
🔗 1. Centralized Single Sign-On (SSO)
Acts as the primary SSO entry portal for all 6 ecosystem projects (mygov, upsheba, fintech, health, passport, tax). Citizens log in once to access all services.
🔄 2. Protocol Mediation & Translation
Bridging different industry standards. Accepts OIDC, SAML2, WS-Federation, or OAuth2 from external apps and translates them into a single federation flow.
🔐 3. Service Provider (SP) Access Control
Manages OAuth client keys, redirect URIs, token lifetimes, and role-based access policies for third-party government applications.
🗺️ 4. Claim Mapping & Attribute Dialects
Filters and transforms claims (e.g. mapping eID uin to WSO2 http://wso2.org/claims/userid) before passing them to application scope.
⚡ 5. Identity Brokering & JIT Provisioning
Delegates authentication to National eID Platform as a Federated IDP, creating local user shadow profiles dynamically via Just-In-Time (JIT) provisioning.
🪪

National eID Platform

Core Identity Vault & Verification Engine
🏛️ 1. Citizen Registry & UIN / eID Generation
Master database of national identity. Assigns Unique Identification Numbers (UIN) and Electronic IDs (eID) with international UN/CEFACT compliance.
📱 2. Multi-Factor Authentication (MFA / 2FA)
Executes 6-digit SMS/Email OTP verification and standard RFC 6238 Time-Based One-Time Password (TOTP) for Google/Microsoft Authenticator apps.
🔑 3. Passwordless Biometrics & Passkeys
Handles W3C WebAuthn / FIDO2 Passkeys (Touch ID, Face ID, Windows Hello) and hardware fingerprint scanner template verification.
✨ 4. Passwordless Magic Link Engine
Generates single-use 10-minute encrypted tokens for email magic link sign-in.
🖊️ 5. 3rd-Party eSignature / PKI REST API Bridge
Connects via REST API to external PKI / eSignature providers to hash, sign, and verify electronic documents on behalf of citizens.
